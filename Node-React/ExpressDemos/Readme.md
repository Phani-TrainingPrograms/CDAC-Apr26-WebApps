# Express
- Express is a NODEJS Package that can be used to develop rich internet based applications in a Rapid manner. 
- It is available as a NODE Package that can be downloaded from NPM. 
```
npm install express
```
- With express, U will install all the dependencies required for the express application. 
- All dependencies shall be available under node_modules. 
- A package.json file shall be created that tells the dev Dependencies for your application if express is installed. 
- With npm, U can get dependency chains for the user. The package.json assists in maintaining the dependencies during the deployment.
- App when deployed shall have package.json and the list of the files that UR application needs. When the user deployes the application, npm reads the package.json and downloads all the dependencies of your project.
